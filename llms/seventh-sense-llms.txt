## Core operations
- POST /liveness — anti-spoofing / liveness score for one image (iBeta L2, ISO 30107-3)
- POST /compare — compare two sets of face images (score 0..1; >=0.81 strong match)
- POST /verify — verify images match a registered person
- POST /search — search registered persons by face image(s)
- POST /detect — detect faces (boxes + landmarks), optionally search
- POST /head-count — count heads/faces in an image
- Persons: POST/PATCH/GET/DELETE /person, GET /persons (skip/take/order/search)
- Collections: POST/PATCH/GET/DELETE /collection, GET /collections

## Notes for agents
- Errors: 422 validation errors return `{ "detail": [ { loc, msg, type } ] }` (not RFC 9457).
- Stateless endpoints (/compare, /search, /liveness, /detect, /head-count) store nothing.
- Register persons (/person) into collections before using /search.
- When installing the SDK, check https://pypi.org/project/opencv-face-recognition/ for the current version rather than pinning a memorized number.
